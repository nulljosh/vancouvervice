# Landmarks

Every place in Vancouver Vice that should be recognisable on sight, where it sits on the game map, and how far along it is. The map is a 16 by 18 grid of 260 unit blocks (`vanMap` in `site/js/data.js`); a cell is written (column, row). Reference renders are in `docs/img/landmark-*.jpg` (Higgsfield, on the brand: night, rain, one red accent). Use them as the target when a landmark is rebuilt.
